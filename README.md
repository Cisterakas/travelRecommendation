# TravelBloom Travel Recommendation

TravelBloom is a travel recommendation web application created as the final project for the [JavaScript Programming Essentials course](https://www.coursera.org/organizations/university-of-immaculate-conception/learn/javascript-programming-essentials) from the University of Immaculate Conception on Coursera.

## Project Objectives

This final project was designed to demonstrate that I can:

- Manage and share a public GitHub repository.
- Deploy a functional website using GitHub Pages.

- Display search results such as beaches, temples, and countries with images.

- Responsive Home, About, and Contact pages.

- Quick-search buttons for beaches, temples, and Japan.
- Clear search, empty-result, loading, and error states.

## Run Locally

Clone the repository and open the project with a local web server:

```bash
git clone https://github.com/cisterakas/travelRecommendation.git
cd travelRecommendation
```

Because the application loads recommendation data from `travel_recommendation_api.json` using `fetch`, use a local server rather than opening `index.html` directly. For example, with Python:

```bash
python -m http.server
```

Then open `http://localhost:8000` in a browser.
